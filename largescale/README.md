# LARGE SCALE TLS STUDY

## Pre-requirement

Test environment: Ubuntu 22.04 LTS

1. Install go-lang (need version >= 1.18)

```
apt install golang-go
```

For manual installation, refer to [https://go.dev/doc/install](https://go.dev/doc/install).

2. Install docker

```
apt install docker.io
```

3. Install python dependencies

```
apt install python3 python3-pip python3-venv
python3 -m venv .venv
. ./.venv/bin/activate
pip3 install -r ./requirements.txt
```

## Run the Test

```
./run
```

## Strategies

1. `zmap` to scan the whole internet to get alive ip with port:

- SMTP: 25, 587, 465, 26, 2525
- IMAP: 143, 993
- POP3: 110, 995
- FTP: 21, 990

2. Scan with `zgrab2`, filter out these who cannot complete a TLS handshake

   We first process the result to generate input.txt for `zgrab2`, then run 
   `zgrab2` to test handshake for all the ip:port generated by step 1.
